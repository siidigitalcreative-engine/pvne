# UI update notes

This update applies a consistent modern UI pass across the shared global stylesheet and the village map screen.

Changes:
- Stronger, more consistent spacing and typography hierarchy.
- Softer card borders and subtle shadows.
- Consistent rounded inputs, buttons, cards, map controls, and block tabs.
- Clearer focus-visible states for keyboard accessibility.
- Responsive map/results layout for tablet and mobile.
- Lot number labels use bold high-contrast text with a white stroke for visibility against colored lots.
- Block selector and lot list remain numerically ordered.

Testing note:
A production build has not been verified in this environment because dependencies are not installed. The SVG lot geometry is still a prototype grid, not verified against the official village plan. Colors in the prototype are illustrative and must be assigned from verified lot data before launch.
