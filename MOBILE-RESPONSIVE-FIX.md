# Mobile responsive fix

- Forces the announcements, events, and poll dashboard panels into a readable single-column stack below 700px.
- Forces business discovery and recent activity into a vertical layout on mobile.
- Keeps community categories in a readable three-column grid.
- Prevents long headings and labels from being split into letter-by-letter columns.
- Restores two-column business cards where space allows and one column on narrow phones.
- Maintains explicit light-on-dark text contrast in the green hero and map promotion.

The production build and real-device/browser overflow checks have not yet been run in this environment.
