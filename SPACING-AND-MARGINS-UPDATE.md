# Spacing and margins update

Added a global spacing system across the site:
- Consistent centered page width and equal left/right page gutters.
- Shared responsive spacing tokens for sections, cards, and elements.
- Consistent internal card padding.
- More even spacing in map tools, block tabs, map/results columns, lot listings, and notices.
- Responsive spacing adjustments for tablet and mobile.
- Stronger, high-contrast SVG lot labels remain in place.

Status:
This is a CSS pass in the project source. A production build has not been verified in this environment. The interactive map's lot geometry is still illustrative and not traced/verified against the official site plan.
