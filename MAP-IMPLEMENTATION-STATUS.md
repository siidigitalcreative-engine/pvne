# Pagsibol Village map implementation status

This update replaces the previous map-image click marker with a clickable SVG lot-map prototype.

Included now:
- Block selector (Blocks 1–6)
- Clickable SVG lot shapes
- Numerical lot IDs (1–40 per prototype block)
- Selection state and selected-lot panel
- Zoom controls and lot-number visibility toggle
- Household/business directory references retained

Accuracy status:
The SVG lot polygons in this first implementation are a functional prototype grid, not yet traced to the exact geometry of the official Pagsibol Village PDF. The real plan does not clearly label formal block numbers, so block-to-plan mapping and all lot boundaries/numbers must be verified block by block before presenting this as the accurate final map. Do not treat sample lot data as official.
