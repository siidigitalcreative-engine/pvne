# Responsive UI reference update

Updated the global visual system to follow the supplied Pagsibol Village dashboard reference: friendly pastel category tiles, a strong green hero, compact quick actions, clean white cards, rounded corners, clear visual hierarchy, and responsive dashboard sections.

Responsive behavior includes:
- Desktop: wide dashboard columns and eight quick-action tiles.
- Tablet: four quick-action columns and reflowed content panels.
- Mobile: compact hero/search, four quick-action columns, three-column topic tiles, and stacked dashboard sections.
- Very narrow screens: two-column quick actions and reduced-width category/business layouts.
- Long text and form controls wrap within their containers; dark green surfaces use light text while white controls retain dark text.

Important: this is a CSS/layout pass. It has not been verified by a successful production build or automated browser-based visual regression test. The village map geometry remains illustrative and still needs tracing against the official plan.
